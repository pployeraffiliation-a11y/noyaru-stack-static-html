Comment verifier les balises canoniques d'un site

La balise canonique indique aux moteurs de recherche quelle URL est la version de reference d'une page. Elle prend la forme d'un element link place dans la section head du document, avec l'attribut rel egal a canonical et une URL absolue dans href.

Ou la trouver

Ouvrez le code source de la page (clic droit puis afficher le source, ou les outils de developpement du navigateur) et cherchez dans le head la ligne rel=canonical. Une page bien reglee ne doit contenir qu'une seule balise de ce type.

Ce qu'il faut controler

Verifiez que l'URL declaree pointe bien vers une page qui existe et repond avec un code 200. Une canonique qui vise une page absente ou une erreur envoie un signal contradictoire au crawl. Assurez-vous aussi que l'URL est absolue, coherente en protocole et en domaine, et qu'elle ne se contredit pas d'une page a l'autre.

Pieges frequents

Plusieurs balises canoniques sur une meme page, une canonique en boucle qui pointe partout vers l'accueil, ou une canonique injectee par un script apres le chargement sont autant de cas qui brouillent l'indexation. Un controle au crawl reel, sur le HTML servi, reste le moyen le plus fiable de les detecter.
